# 页面与交互规格

版本：2.1 · 原始基线：2026-10-10 · 修订：2026-10-11 · 状态：当前需求与实现基线。

## 信息架构

左侧导航：概览、物料、BOM、销售单、排产工作台、生产单、批次追溯、演示与日志。批次追溯可从销售/生产详情直接进入，不必单独新建“批次管理”编辑页。

顶部显示当前演示场景、数据世代和“演示系统”。不提供用户头像、角色选择或后台管理入口。

## 页面规格

| 页面 | 信息 | 操作和校验 |
|---|---|---|
| 概览 | 待排销售行、待确认建议、等待/可开工/生产中/完成的生产单数 | 跳转过滤列表；不显示库存、产能利用率或虚构交期 |
| 物料 | 编码、名称、类型、单位、启用、默认 BOM | 新建、编辑、停用；引用后的类型/单位锁定并说明 |
| BOM 列表/详情 | 版本、基准产量、直接明细、任意深度展开、共享节点标识 | 编辑草稿、复制版本、激活、退役；错误定位具体环路/缺失组件 |
| 销售单列表 | 单号、客户、状态、确认时间、生产进度、未安排提示 | 新建、过滤、详情 |
| 销售详情 | 行数量和单位、优先级、已安排/待排数量、关联顶层单、等权计算 | 草稿商品仅可用BOM制造项；确认；未完成/已完成销售均可取消并预览逐批数量；已确认字段只读 |
| 排产工作台 | 需求池、建议表、来源分配矩阵、用量和占比 | 拆分、合并、分配、保存校验、确认；刷新将覆盖未确认人工调整时明确提示 |
| 生产单列表 | 单号、独立批次、物料、数量、优先级、状态、总进度 | 可开工优先筛选；总进度不是输入框 |
| 生产详情 | 子单、各自总进度、直接平均、w、自身M、总T、阻塞、来源、原料 | 开始、自身进度调整、完成单更正、上下游追溯 |
| 追溯 | 相对销售的路径、冻结层级、批次分配数量、使用确认、历史替代 | 销售向下与批次双向追溯；历史开关及取消的虚线无效边；重复引用不重复汇总产量 |
| 演示与日志 | 清空重置预览、操作时间和变化；场景恢复说明见18 | 确认后重置；日志按单据/request过滤，无操作人 |

## 生产详情的必需表达

示例卡片：

```text
总进度 36.00%       状态：等待子单完成
子单贡献：平均60.00% × 占比60.00% = 36.00%
自身贡献：自身0.00% × 占比40.00% = 0.00%
当前阻塞：B-001 尚未完成（60.00%）
[开始生产：禁用] [自身生产进度：禁用]
```

子单全部完成时显示“可以开始生产，总进度60.00%，尚未开始本级加工”，不能用“未开始=0%”的错误视觉规则。

进度输入标注“本级自身生产进度”，输入范围0～100，步进0.01。提交前展示新的总进度预览；最终以服务端返回为准。降进度或完成后更正必须填写原因。w=100%的节点隐藏手工加工输入，显示“由子单完成自动完成”。

## 排产调整

- 合并候选只显示兼容物料、版本和优先级，用户仍可查看不可合并原因。
- 拆分弹窗输入各份数量，总量必须守恒；同时展示新的供应/销售分配矩阵，未分配满不能确认。
- 建议节点改变后重新计算原料及上下游数量。非叶节点显示占比输入，叶节点隐藏占比。
- 未确认建议可以重算；若存在人工修改先解释会被替换，可取消。正式计划不会被刷新改变；新增销售形成新草稿，不能追加到既有正式批次；销售取消通过专门动作缩量。
- 确认结果展示计划、全部生产单和批次；前端点击后禁用按钮，后端幂等防重。

## 销售进度展示

单头明确列出参与平均的 distinct 顶层生产单及总进度。两行引用同一顶层单只计一次。没有安排任何生产单时显示0%和“待排产”。部分安排时显示“已安排部分生产进度xx%，另有待排需求”，不把此指标包装成全单履约率。

完成状态文本使用“生产已完成”。不出现“已发货”“可交付xx件”或收款提示。

## 错误、撤销、刷新与重置

错误消息显示服务端原因；单据详情与追溯入口由列表及详情页提供。冲突时保留用户未提交输入，提示刷新，不自动覆盖服务端新状态。

撤销影响弹窗列出全部受影响销售、生产单和批次；说明将撤销整个计划。已有生产操作时禁止整计划撤销并说明原因。销售取消使用独立预览，列出逐批旧/新数量：独占单撤销、共享单缩量、已完成量保留重算，不撤销其他销售的分配。已开工销售也可取消。

写操作成功后刷新变化单据、销售、列表和概览；其他打开页面激活/聚焦时检查修订号，当前不依赖定时轮询保证正确性。网络失败不先把本地显示改成成功，不离线排队写入。

重置弹窗明确会删除演示业务和旧日志，保留编号序列；点击“重置为空数据”后在影响弹窗点击“确认清空”。当前没有“重置为所选场景”菜单，已授权初始场景通过18的备份恢复，不放入测试夹具。重置后清空前端所有缓存，加载新 epoch。收到 STALE_EPOCH 时提示“演示数据已重置，请刷新”，禁止重试旧写请求。

## 可用性与视觉验收

1366×768 与1920×1080桌面尺寸可完成主要流程。宽表横向滚动，依赖图可拖动和缩放；必须同时显示状态文字而非只靠颜色。键盘可操作主要表单和弹窗，进度输入有明确标签，金额/财务字段不出现。

空数据、加载、请求失败、无搜索结果、缺失BOM、无待排需求都提供明确状态。演示页面不暴露数据库字段名、事务、幂等键等实现细节。

销售草稿商品选择器只显示启用、允许销售且具可用BOM的成品/半成品，保存和确认均由后端校验。已取消销售不再显示待排量；取消前进度可作为历史显示，不重新参与当前需求。含取消进度记账的生产详情说明总进度可能高于常规子单公式。

物料列表显示“可销售”；半成品新增和编辑提供“销售设置”开关，新建默认“仅供生产使用”。成品和原料资格固定。BOM父项选择启用的成品/半成品，不要求已有BOM，也不受销售资格限制；不可销售半成品仍能建立BOM和参与生产。

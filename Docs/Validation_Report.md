## 可重复检查

在项目根目录运行：

```sh
python3 Docs/tools/check_docs.py
```

脚本检查本地Markdown链接、需求/测试编号引用、需求追踪覆盖、代码围栏、JSON示例、PlantUML边界及独立数量/进度算例。脚本只读文档，不生成最终演示数据、不访问数据库、不修改业务文件。

# 产品范围与术语

版本：2.1 · 原始基线：2026-10-10 · 修订：2026-10-11 · 状态：当前需求与实现基线。

## 目标与成功标准

演示跨销售单、多层 BOM 的生产计划与进度反馈。观众应能回答：为什么需要生产这些产品、为什么可以合并、哪张子单阻止父单开工、百分比怎么算出来、最终产品使用了哪些生产批次。

成功标准：完整走通销售确认至生产完成；状态限制不能绕过；数量守恒；批次关系可双向查询；重启保留数据；重置后能重复验证。开发测试使用隔离临时数据；开发完成后已按用户文档建立蒜蓉酱演示初始数据及备份，讲解脚本和一键场景菜单未交付。具体判据见 [测试验收](09_Test_Acceptance.md)。

## 范围

包含物料、单位、BOM 版本、销售单及行、待排需求、建议拆合、生产依赖图、人工进度、独立批次、分配数量、追溯、操作记录、演示恢复和单容器交付。

明确排除：用户和角色、登录、授权、库存余额和预留、采购到货、产线和设备、有限产能、可信交期预测、财务、发货、质量、报废、返工、超产/欠产处理、外部 ERP 对接。BOM 计件取整导致的明确余量只作为计划余量解释，不形成库存；销售取消时可保留已完成量重算比例，超出剩余需求的量视为完成并忽略，不建立库存。

无账号也应保留服务端校验、事务、输入检查、同源请求和防重复提交；这些是正确性机制，不是权限体系。不记录操作人，不建立用户表或后台登录入口。

## 术语

| 术语 | 定义 |
|---|---|
| 物料 Item | 成品、半成品或原料，具有唯一编码及固定单位 |
| 成品 | 可销售；BOM 直接组件只允许半成品和原料 |
| 半成品 | 可配置是否销售，新建默认不可销售；也可作为其他制造物料的组件 |
| 原料 | 不销售、不展开、不生成生产单、不参与进度和开工门槛 |
| BOM | 一定基准产量的父物料所需的子项及用量 |
| 建议单 | 未确认计划中的临时生产节点，无正式生产批次 |
| 生产单 / 生产子单 | 同一种实体；相对于下游产品，其供应节点称子单 |
| 父单 / 消费单 | 使用子单产出的上级生产单 |
| 顶层生产单 | 相对于一条销售行，直接产出该销售物料的生产单；不是全图中必须无父节点 |
| 自身进度 M | 用户手工登记的本级加工百分比 |
| 总进度 T | 常规子单贡献公式与取消保留完成量进度下限的较大值，上限100% |
| 子单占比 w | 子单对本单总进度的贡献，0%～100% |
| 批次 | 一张正式生产单的唯一产出批次；本期一单一批次 |
| 分配关系 | 批次向父批次或销售行提供的数量，不是库存出入库 |
| 计划层级 | 确认计划时固定的层级标签，供编号使用 |
| 追溯路径 | 某销售行至批次及其所有上游投入批次的实际图路径 |
| 撤销 | 使正式计划或零需求批次失效并保留历史；重新计划使用新编号 |
| 销售取消 | 移除对应销售分配；独占批次撤销，共享批次原地缩量，子单和进度同步重算 |
| 保留完成量 | 取消前计划量乘以精确总进度，只用于取消后的进度记账，不是可交付量或库存 |

## 输入、输出与使用者

使用者只有“演示操作者”，没有权限划分。

输入：物料/单位、BOM、销售数量和优先级、建议调整、子单占比、手工生产进度。

输出：生产建议、正式生产单、原料需求、依赖和阻塞原因、多级总进度、销售生产状态、批次追溯和操作日志。

数据语言为中文；时间存 UTC、显示 Asia/Shanghai；数量单位沿各物料定义，禁止把瓶、箱、公斤直接相加。无多币种、金额或客户主数据模块；销售单仅保留客户名称文本。

## 示例结构要求

不同包装 SKU 共用同规格中间产品；中间产品可继续拆解，开启销售资格后可直接销售。销售草稿商品必须已有完整可用BOM，不同优先级不合并，但可先手工完成LOW；多个父单可共享同一子单。当前已授权演示主题为蒜蓉酱A/B/C包装，共用瓶装及酱料半成品，见 [演示BOM](18_Demo_BOM.md)；测试数据仍隔离，见 [数据政策](13_Test_Data_Policy.md)。

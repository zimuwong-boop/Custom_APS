# Custom APS · 生产排产演示系统

从销售订单出发，演示多级 BOM 排产、生产进度反馈和批次追溯。不考虑库存和产线产能，无需登录。

- **订单优先级**：支持高、普通、低三级；生产子单继承优先级，不同优先级不合并。优先级用于分组，不强制生产先后顺序。
- **生产建议**：销售单确认后，自动展开多级 BOM，将同产品、同 BOM 版本、同优先级的需求汇总为建议，交由用户调整和确认。
- **拆单与合并**：建议可拆成多个批次，也可将符合条件的单据重新合并，保留销售来源及数量分配。
- **进度反馈**：手工更新生产进度，子单全部完成后父单才能开工；进度逐级反馈至销售单。
- **批次追溯**：每层生产单都有独立批次号，可从销售单追查相关批次，也可从批次反查生产关系和销售去向。
- **销售取消**：独占批次取消，共享批次扣除对应数量，下级需求和进度同步重算。

采用 Django + Vue + SQLite，单 Docker 容器部署。

详细设计、演示数据及运行说明见 [Docs](Docs/README.md)。

## Docker 快速部署

安装并启动 Docker（含 Compose v2），从 [GitHub Releases](https://github.com/zimuwong-boop/Custom_APS/releases/latest) 下载并解压完整部署包，然后在 macOS / Linux 终端执行：

```sh
cd deploy
./start.sh
```

打开 http://127.0.0.1:8000 。部署包自带 ARM64 / AMD64 镜像和初始演示数据：20 张已确认销售单、待确认排产建议，无正式生产单。重启保留操作结果，使用独立数据卷，不覆盖原实例。

若直接克隆源码仓库，先在 `deploy` 目录执行 `./build-image.sh` 联网构建镜像，再启动。

恢复初始演示状态（自动备份当前数据）：

```sh
./reset-demo.sh --yes
```

ARM64 已通过启动和恢复验证；AMD64 已完成构建及镜像导入，运行验证尚未完成。完整部署包、端口设置和使用说明见 [deploy](deploy/README.md)。

Railway 云端单实例部署配置见 [deploy/railway](deploy/railway/README.md)。
